Tailwind CSS

Utility-first CSS framework for rapid UI development.
1. Install
npm install tailwindcss @tailwindcss/cli
2. Create your input CSS file File: src/input.css
@import "tailwindcss";
3. Start the build
npx @tailwindcss/cli -i ./src/input.css -o ./src/output.css --watch;
4. Link the output in your HTML File: index.html
<link href="./src/output.css" rel="stylesheet"> <h1 class="text-3xl font-bold underline">Hello</h1>
5. CDN (quick start, development only) File: index.html
<script src="https://cdn.jsdelivr.net/npm/@tailwindcss browser@4"> </script>
